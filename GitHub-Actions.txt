Github Actions:-
==================
Built in CI CD tool in Github
Automates tasks like testing,Building,Deploying the code
Works like a virtual Assistant for developers
Improves Code quality
Auto Deployment
Scalable and secure 
Automated process that runs based on triggers
defined using .yaml files (workflow files) stored in .github/workflows/ folder
can run on different operating systems (Windows, Linux, Mac)



Github Actions Workflow:-
===========================
A Github Actions workflow consists of 3 components:
1.Workflow (.yaml file)   //The entire automation pipeline
2.Events (when workflow runs)  //Triggers for the workflow
3.Jobs (steps to be executed)  //Sequence of tasks to be executed
4.Step:- Individual task within a job
5.Runner:- The machine that runs the job
6.Actions:- Reusable code that performs specific tasks


Workflow Execution:-
========================
event occurs ->workflow starts ->job executes in parallel(by default)->inside job->steps executed sequentially (by default)->tasks complete->workflow finishes

workflow:-
===============
github->create a new repo->Actions->set up a workflow yourself (yml=Ain't Markup Language) ->write code in main.yml format ->commit changes

eg:-name: Shrinidhi N K
on:
 push:
   branches: [main]
jobs:
  demo:
    runs-on: ubuntu-latest
    steps:
     - name: Greetings
       run: echo "Hello from James"
   

yml:- indentation is important

cron:- Time based scheduler :- commond run on :- min,hours,date,month,week

Disable workflow:-
=========================
1.Disabled inside workflow yml file
2.Disabled inside repository settings->Actions
3.Delete workflow file from .github/workflows/ folder
4.Pushing "[skip actions]" or "[no actions]" in commit message

it is done to disable the workflow temporarily 
actions:- name: Disable Workflow
on:
  push:
    branches: [ main ]

jobs:
  disable:
    runs-on: ubuntu-latest

    steps:
      - name: Shrinidhi
        run : echo "Disable workflow Video Devops"


Actions:- Disable Workflow :- 3 dots :- Disable or enable workflow
workflow will not run until we manually enable it/ when we disabled it

Trigger:-
==============
Events:- push,pull_request,schedule,workflow_dispatch,release
Event Triggers:- when push,pull_request,release occurs
schedule Triggers:- when schedule,cron occurs
Manual Triggers:- when workflow_dispatch occurs


In workflows we can use MarketPlace like "checkout" or "NodeJs" or "npm" etc , to use its actions
this is done while setting up workflow github actions for react/nextjs/angular etc, or in the workflow file.

checkout:- This is a GitHub action that is used to check out the code from the repository.

NodeJs:- This is a GitHub action that is used to run the nodejs code.

npm:- This is a GitHub action that is used to run the npm commands.

Building React-App using Github Actions Workflow:-
===========================================================
actions:- select a workflow->name: Build My React App

on:
  push:
    branches:
      - master

jobs:
  build-react-app:
    runs-on: ubuntu-latest

    env:
      FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: true

    defaults:
      run:
        working-directory: first

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v5

      - name: Setup Node.js
        uses: actions/setup-node@v5
        with:
          node-version: 24
          cache: npm
          cache-dependency-path: first/package-lock.json

      - name: Install Dependencies
        run: npm install

      - name: Build React App
        run: npm run build


Artifacts and Caching
==================================
Artifacts:- Output generated by jobs
Caching:- Speed up subsequent workflow runs by caching dependencies
 eg:-it cache the node_modules folder , we can skip npm install every time

example:- 

name: React Build with Artifacts and Caching
on:
  push:
    branches:
      - master
jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 24
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Build React app
        run: npm run build

      - name: Upload Build Artifacts
        uses: actions/upload-artifact@v4
        with:
          name: build-output
          path:
            build/        # React build folder
            
Job CunCurrency:-
=====================
By default it runs in parallel jobs unless we define sequence using "needs"

 eg:-

 name: Sequential Job Execution
on:
  push:
    branches:
      - master

jobs:
  build:
    runs-on: ubuntu-latest

    concurrency: 
      group: deploy 
      cancel-in-progress: true  # cancel previous if any
      
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v5
        
      - name: Setup Node.js
        uses: actions/setup-node@v5
        with:
          node-version: 24
          cache: npm
          cache-dependency-path: package-lock.json

      - name: Install Dependencies
        run: npm install

      - name: Build React App
        run: npm run build

      - name: Deploy to Production
        run: echo "Building the App"


Environment Variables in Workflows
=================================================
Used to pass configuration values to jobs
Set globally (workflow level) or per job
Available to all steps within the job

Example:

name: Workflow with Environment Variables
on: workflow_dispatch
jobs:
  build:
    runs-on: ubuntu-latest

    env:
      APP_ENV: development
      API_URL: https://api.example.com

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Use Environment Variables
        run: |
          echo "App Environment: $APP_ENV"
          echo "API URL: $API_URL"


Conditional Triggers
=========================================================
Workflows can be triggered based on conditions
Use expressions with `if` keyword
Commonly used with pull request branches, tags, or specific files

Example:

name: Conditional Workflow
on:
  pull_request:
    branches:
      - master
    paths:
      - 'src/**'
      - 'package.json'

jobs:
  build:
    runs-on: ubuntu-latest
    if: github.actor == 'shrinidhink21'   # Only runs for this user
    steps:
      - name: Checkout code
        uses: actions/checkout@v4
      - name: Build React app
        run: npm ci && npm run build
