What is a Tag?
===============
A permanent name pointing to a specific commit.Tags never move

git checkout v1.0
git log --oneline --decorate

Types of Tags:-
===================
1)Lightweight Tag :- Just a pointer. 
==================
git tag v1.0
No extra information.

2)Annotated Tag:-
==================
git tag -a v1.0 -m "First stable release"
Stores

Author
Date
Message
Checksum

Think of it like a mini commit for releases.

How to tag:-
================
git log --oneline
git tag v1.0 98a1234

delete tag:- git tag -d v1.0 

Push one tag :- git push origin v2.0
Push all tags :- git push origin --tags
Delete Remote Tag :- git push origin --delete v2.0

=================================

Create More Commits
===================

Tag an Older Commit
====================
git log --oneline
git tag v0.9 cb99a31
git tag

Create an Annotated Tag
========================
git tag -a v2.0 -m "Second stable release"
git tag

Inspect Annotated Tag
==================
git show v2.0

git push origin master  //Tags are NOT pushed.
git push origin v2.0  //Push One Tag
git push origin --tags   //Push All Tags

Delete Local Tag
=================
git tag -d v1.0
git tag

Recreate Deleted Tag
====================
git tag v1.0
git tag

Push Recreated Tag
====================
git push origin v1.0  

Delete Remote Tag
====================
git push origin --delete v2.0

Checkout Old Version
==========================
git checkout v1.0
git status

Create Branch from Tag
=======================
git switch -c release-fix

Make a Hotfix
===============
echo "Bug Fixed" >> app.txt
git add .
git commit -m "Hotfix for Version 1.0"

Return to Master
===================
git switch master
git branch

Visualize Everything
======================
git log --oneline --decorate --graph --all
git show v1.0
git show v2.0

List Tags with Messages
==========================
git tag -n

Collaboration: Multiple people can work on the same project
simultaneously.

Branching and Merging: Users can diverge from the main base of code,
experiment, and then bring changes back in line without losing work.

Tracking Changes: You can see specific changes made and by whom.

A git commit is a command in Git that captures
a snapshot of the project's currently staged
changes, creating a permanent record in the
repository's history.
